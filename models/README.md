Nuestro robot
===

Nuestro automóvil es un robot cuya base y chasis fue diseñado totalmente desde cero. El robot se compone por más de 10 piezas fundamentales para su armado, desde las bases para cada uno de los componentes, hasta los diferentes pisos y mecanismos como lo es el direccional y la transmisión trasera para el motor y las llantas de esa zona. La distribució de cada uno de los elementos esta hecha para que los sensores abarquen el mejor ángulo posible y puedan brindar la mejor información a nuestra Raspberry Pi 5, la cual se ubica en el segundo piso. La base para la cámara se diseño en 3D para que fuera posible ajustarla según nuestra necesidades. Todos los diseños incluidos fueron utilizados en el proceso de armado del vehículo autónomo, así como un pequeño modelo de como se puede llegar a ver el robot ya armado

Se tomo la decisión de crear el carro de esta forma en base a nuestra experiencia en la competencia regional, donde aprendimos de nuestros errores anteriores y notamos las siguientes problemáticas:

* El robot era demasiado grande, lo cual dificultaba el maniobraje de este mismo.
* El diseño tenía una pésima distribución del peso lo que ameritaba fallas en zonas vulnerables, esto ocasionaba que se cayeran algunas piezas o que el carro fuera muy fácil de romperse.
* La vara direccional era muy propensa a debilitarse o doblarse con el estrés de las pruebas.
* Las piezas no estaban puestas de forma correcta y los componentes se desconectaban de forma constante.

Para resolver las dificultades anteriormente mencionadas se tomaron varias decisiones para el resultado que estamos presentando, las decisiones fueron:

* Hacer bases más pequeñas, agregar más pisos y reducir el tamaño de las llantas, transmisión y sistema direccional, todo esto para reducir significativamente el tamaño del automóvil.
* Reforzar el material y planificar una distribución del peso más idónea para la durabilidad de nuestro robot.
* Fabricar una vara direccional con aluminio, esto benefició enormemente a nuestro proyeco gracias a la reducción en el desgaste de esta misma, se pudo evitar el tener que cambiarla constantemente y ahorrarnos tiempo de armado.
* Organizar el cableado y mejorar las soldaduras utilizadas para evitar fallos por desconexiones o rompimiento de cables.
